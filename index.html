GitHub Pages Deployment Guide

  1. Create a GitHub Repository: Go to github.com and create a new repository (e.g., voxel-craft). Set it to Public.
  2. Save this HTML File: Save this complete single-file code as index.html on your local computer.
  3. Upload to GitHub: Upload index.html to your newly created repository root branch (main or master).
  4. Enable GitHub Pages:
    • Navigate to Repository Settings → Pages.
    • Under Source, select Deploy from a branch.
    • Set Branch to main (or master) and folder to / (root).
    • Click Save.
  5. Play Online: After ~1-2 minutes, GitHub will generate a URL like https://yourusername.github.io/voxel-craft/. Your 3D Minecraft game is live!
